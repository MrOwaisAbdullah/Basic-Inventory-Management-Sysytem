# Basic Inventory Management System

A responsive client-side web application for small businesses and stores to track products, stock levels, and inventory transactions.

## 📦 Features
- **Product Management**: Add, update, and delete inventory items.
- **Stock Tracking**: Monitor quantities, unit prices, and total inventory valuation.
- **Persistent Storage**: Real-time client-side persistence.

## 🛠️ Tech Stack
- **Language**: TypeScript, JavaScript
- **Markup & Styling**: HTML5, CSS3
